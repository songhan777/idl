执行命令：

```text
python scripts/verify_contract.py
python -m unittest discover -s tests -v
python -m pip check
pnpm generate
pnpm validate

```

`pnpm validate` 依次执行 lint、生成差异检查、TypeScript 检查和客户端测试。浏览器阅读版使用无头 Edge 检查目录、溢出与契约快照，并进行了桌面、幂等章节和移动视口的图像查看。
